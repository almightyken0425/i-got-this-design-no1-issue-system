DESIGN RULES

同一個方向，整套延伸。

2026.10.14 · 使用者選定

禁止 checkbox、radio 及仿造外觀。也不以空心方框、空心圓圈或勾選圈表示任務完成與選取。

01 / 配色角色

白與冷灰承載內容。藍色只標示主要動作、目前位置與重點。狀態靠形狀、分組與短標籤辨識。

色票直接讀取 tokens.css，同一份值也套用在畫板。SVG 插畫的灰藍明暗只屬素材。

02 / 文字與圖像

  • 標題、狀態、日期保留必要文字，刪除重複的說明句。
  • 常用動作採圖示。每個圖示按鈕都有可及名稱與滑入、聚焦提示。
  • 縮圖使用真實附件或內容預覽。沒有素材時改用型別圖示，不為填空捏造插畫。
  • 長標題在卡片截斷，完整名稱可從詳情與輔助技術讀取。不可改寫真實工單標題。
  • 表單標籤、錯誤與權限原因保留精簡文字。危險動作不能只靠圖示猜測。

03 / 元件形式

階段模組
橫式卡片
圖示按鈕
內容縮圖

淺灰模組裡放白卡片。縮圖在左，短標題在右，日期與人員退居第二層。薄邊線與極淡陰影只用來分層。

以上為桌面基準。總覽容器 17px，窄版模組 16px、進度面板 15px。不要把所有圓角改成同一值。

04 / 比例與結構

  • 桌面左側 56px 圖示導覽，工作區與側欄間隔 22px。
  • 總覽高度 174px，進度區 185px，剩餘空間給主要內容。
  • 看板採兩欄階段模組，模組間距 17px。階段數由真實流程決定。
  • 橫式卡片最低 82px，縮圖 89 × 64px。標題 13px，主標題 29px。
  • 字體採系統黑體與 PingFang TC。重要資訊不能照抄原型中 10px 的示範輔助字級，正式畫面優先可讀性。

05 / 動作與狀態

  • 點卡片開詳情。狀態從可執行的轉換選單更改，不能自由跳過 workflow 限制。
  • 切換檢視用頁籤。單選設定用下拉選單，多選使用加入／移除操作與已選項目，不內藏 checkbox 或 radio。
  • 布林欄位以目前值加變更選單表達。完成狀態以分組和封存圖示表達，不放勾選控制。
  • 載入、空白、錯誤、無權限、儲存中都要有狀態。數字不能用假資料補齊。
  • 鍵盤能進出選單與詳情，關閉後焦點回原入口。減少動態偏好下取消裝飾位移。

06 / 尺寸與可用性

  • 800px 以下導覽移到底部，540px 以下階段模組改單欄。
  • 窄版可收起次要資訊，但詳情仍可取得完整資料。
  • 觸控版擴大點擊區，避免把原型 38px 圖示按鈕直接當成唯一觸控目標。
  • 必驗鍵盤、320px 與 390px 寬、長標題、200% 放大及空資料。
  • 前景與底色須保持足夠對比。裝飾邊線不作唯一狀態提示。
